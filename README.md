NBTSTAT:

NBTSTAT (NetBIOS over TCP/IP Statistics) is a command-line tool used to display NetBIOS name tables and statistics for NetBIOS over TCP/IP connections. It is mainly used to view NetBIOS names registered on a computer, check the NetBIOS name cache, monitor NetBIOS connections, and troubleshoot NetBIOS name resolution problems in a network. NetBIOS (Network Basic Input/Output System) is the protocol that allows computers in a Local Area Network (LAN) to communicate and share resources.

ARP:

ARP (Address Resolution Protocol) is a network protocol used to find the MAC address of a device when its IP address is known. It works in a Local Area Network (LAN) by mapping the IP address to the physical MAC address of a device. ARP is mainly used to enable communication between devices in a network and ensure that data packets reach the correct device.

SYSTEMINFO:

systeminfo is a command-line tool used to display detailed information about a computer’s system configuration. It shows details such as the operating system version, processor, memory (RAM), system manufacturer, BIOS version, and network information. It is mainly used to check system specifications and troubleshoot system-related issues.
